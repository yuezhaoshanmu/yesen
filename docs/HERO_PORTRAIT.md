# 首页人物展示

## 图片与真实性

- 原件：项目根目录 `1.png`，1122 × 1402，RGB、灰色摄影背景，保留不覆盖。
- 页面唯一人物来源：`public/images/1.png`，同尺寸 RGBA 透明背景，最终文件名不变。
- 原照片拍摄至大腿，未包含小腿和脚；完整保留已有拍摄范围，不生成缺失身体。
- 使用本地 rembg / ISNet 分割，仅采用透明度蒙版。所有可见像素的 RGB 与原件逐像素一致；没有美颜、重新绘制、换脸或颜色滤镜。
- 在浅色、深色背景下检查了头发、眼镜、西装、手部与手臂内侧空隙。
- 可选重处理脚本：`scripts/prepare-portrait.py`，需要独立 Python 环境安装 `rembg[cpu]`。重处理后应再次检查边缘；不属于 npm 构建步骤。

## 布局与反馈

- 桌面：介绍与人物双栏，六项核心成果位于下方；iPad 竖屏使用双栏人物与三列成果。
- 手机：介绍、核心成果、人物依次显示，使用 contain 完整展示原图内容。
- 人物仅首次进入淡入并上移 20px，800ms，无桌面 hover / tilt / 鼠标跟随 / 视差。
- 真正的 touch pointer 轻点后，200ms 内从 1 缩至 0.98 再恢复；鼠标不触发。滚动取消与移动超过 10px 不触发反馈。
- 减少动态效果偏好下停用入场和触摸动画。人物无按钮角色、Tab 停靠或跳转，alt 为“叶森个人形象照”。
- 使用 next/image、priority、响应式 sizes、quality 85；页面不直接下载高分辨率 PNG。
