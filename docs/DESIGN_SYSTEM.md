# 数字荣誉展厅设计系统

底色 #050B10；表面 #0A131A；正文 #EAF0EF；次级文字 #B5C2C4；辅助文字 #8B9FA4；翡翠 #94DFC3；社会实践冷金 #D6BB90。

设计以“有凭据的成果”为焦点。深色展厅承托真实证书，Google 区域采用明亮银白色，形成有意义的叙事转场。画面以 1 px 细线、空白、轻量光晕和系统字体建立层次，避免背景效果抢夺事实。

桌面内容宽度不超过 1320 px。章节标题 31–45 px，姓名 104–145 px，主数字最大 150 px。手机以 20 px 页边距、单列证书墙、双列首屏指标与独立导航菜单重新编排。

所有证书 object-fit: contain，不用裁切制造美观。图片延迟加载；原件按需打开。交互统一为查看证明、访问项目、官方验证。只有真实来源能支持的验证 URL 才出现按钮。

动效主要采用 transform、opacity。首屏慢速旋转安全核心；卡片微倾斜最大约 1.5 度；数字 1.1 秒缓出；滚动揭示 0.9 秒。无强制加载幕，无滚动劫持。减少动态效果设置下禁用动画、自动滚动与倾斜。
