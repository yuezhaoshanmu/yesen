## 外部链接与项目

CVE 链接仅由材料明确出现的四个编号构建。Coursera 链接来自 PDF 内真实注释 URL。其余未提供可核对官方详情 URL 的证书只显示查看证明，不构造链接。

三个用户指定项目 HTTPS 均响应 200；浏览器实际加载后获取标题/页面内容及截图。颐护家、银童共育有真实 title；夜幕牌局以 H1 为名。未发现 favicon、OG Image 或 description，使用实际页面截图，不虚构产品界面或技术栈。对外可用性随远端状态变化；产品功能描述来自其页面说明，不代表全部登录后流程经过测试。
